# The types that hold a tracked word, one per line: the page that documents the type, then its fully
# qualified name as the page's title gives it. A page here carries, directly under its names block, the line
#
#   **Requires [rooted](../../../core/rooted/README.md) outside a stack or a managed object.**
#
# and a page of a class not here carries none (tools/lint_docs.py, the `rooted` check; docs/STYLE.md, the page
# of a class). A page that documents two types (fold_matches, normalized_matches) has a line for each.
#
# Decided from the code, never from what a page says: a type is here when its layout holds a tracked word,
# directly or through a member, a base or an alternative, recursively: a tracked_ptr (a detail::Pointer), the
# word of an any or a function (detail::ValueStorage), a variant or an expected with an alternative that holds
# one. A container of T holds one whatever T is. A root_ptr, a rooted, a unique_ptr and the coroutine types
# that hold their frame by a root_ptr (async::task, generator, async::blocking_task) hold none. Checked with
# clang's record layouts of every documented type (-Xclang -fdump-record-layouts) and, where a type has a
# default constructor, a Debug build constructing it in malloc memory (the tracked_ptr placement assertion).
#
# Not here, as templates whose instances differ (the type holds a tracked word only when its arguments do):
# expected<T, E>, unexpected<E>, variant<Ts...>, array<T, N>, the std aliases (optional, pair, tuple),
# async::operation<F> (the closure of the waiting call) and txt::formatter<T>.
