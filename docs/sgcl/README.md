# The sgcl reference

One page per public class or function of the library, each with every public member, its signature as declared
in the header, and an example that compiles. The guide, the rules and the benchmarks are in the
[main README](../../README.md); this is the reference to come back to.

## Modules

The library is fifteen modules, one directory each in `sgcl/` and here, each with a README of its own that is its guide (what the classes are, the rules, what to reach for) before it lists them:

| Module | Description |
|---|---|
| [async](async/README.md) | coroutines, the scheduler, executors and strands, task-local values, `channel`, `select`, `broadcast`, timers and the clock, the signals of the process, `stop_token`, `when_all`/`when_any`, `task_group`, `timeout`, `mutex`, `shared_mutex`, `semaphore`, `event`, `wait_group`, `once`, `condition_variable`, `promise`, `spawn_blocking`, the reactor |
| [codec](codec/README.md) | images — `codec::image` (a one-word handle, nine pixel formats, `convert`, orientation, EXIF and ICC as bytes), `codec::load` and `codec::decode` by signature, `image.save`/`codec::save` by extension, `png` and `jpeg` (decode and encode), `gif` (decode, `frames` for animation), `webp` (lossless and lossy, alpha, animation), `heif` (HEIC, HEIF and AVIF through the system's codec, HEIC written), `codec::error`, `limits` |
| [compress](compress/README.md) | `flate`, `zlib`, `gzip` (both ways; `compress`/`decompress` in memory, `reader`/`writer` as io streams, `level`, `limits`), `bzip2` (both ways), `lzw`, `lzma` (`.lzma` both ways), `xz` (`.xz` both ways: LZMA2, the branch converters, Delta, the four checks, several streams), `lz4` (frames and blocks both ways, levels 1 to 12), `snappy` (framed and blocks both ways), `zstd` (both ways, levels 1 to 22 and `--fast`, dictionaries), `brotli` (both ways, qualities 0 to 11, the static dictionary), `zip` (`archive`, `writer`, `entry`, ZIP64), `tar` (`reader`, `writer`, `entry`: ustar, pax, GNU), `sevenzip` (`archive`, `writer`, `entry`, `walk`: 7z both ways, 7zAES, Deflate64 read); `compress::error` |
| [concurrent](concurrent/README.md) | the lock-free containers, `concurrent::bounded_queue`, `concurrent::priority_queue`, `concurrent::cache`, the concurrent weak containers, `intern`, `copy_on_write` |
| [core](core/README.md) | the collector, `tracked_ptr`, `unique_ptr`, `root_ptr`, `weak_ptr`, `make_tracked`, `variant`, `any`, `function`, `expected`, `range`, the configuration; the containers (the sequences, maps and sets, `weak_map`, `weak_set`, `expiry_queue`), `atomic`, `atomic_ref`, `clock`, the managed coroutine frame and `generator` |
| [crypto](crypto/README.md) | the digests (`sha1`, `sha256`, `sha512`, `sha3`, `shake`, `hash_id`), `hmac`, `hkdf`, `pbkdf2`, `random`, `constant_time`, `secure_zero`; the AEADs `aes_gcm`, `chacha20_poly1305`, `xchacha20_poly1305` and `nonce_counter`, the bare `aes`, `aes_ctr`, `chacha20`; `x25519`, `ed25519`, `p256` and `p384` (ECDH, ECDSA), `rsa` (PKCS #1 v1.5 and PSS signatures, OAEP), `x509` (certificates, pools, the verification of a chain with the host name, the reason when it fails), `secret`; on the processor's crypto instructions on arm64, plain C++ elsewhere; `crypto::error`. Not independently audited |
| [encoding](encoding/README.md) | a type per format — `asn1` (BER and DER, an element read and written), `base64`, `base32`, `hex` (with `dump`), `ascii85`, `pem`, `big_endian`, `little_endian`, `varint`; strict by default, `lenient()`; the codecs as `io` streams; `json` (an immutable value, `json::reader`, `json::writer`), `csv` (`reader`, `row`, `writer`), `xml` (reader, writer, an immutable tree, namespaces, no DTD), `field_list` (a program's types described once for every format: `describe(field_list&)`); `uuid` (RFC 9562); `cbor` and `msgpack` (one value, both formats); `yaml` (YAML 1.2); `toml` (TOML 1.0, dates and times typed); `ini` and `dotenv` (configuration files); `icalendar`, `recurrence` and `vcard` (RFC 5545 with RRULE expansion, RFC 6350); `json_schema` (JSON Schema 2020-12); `encoding::error` with the offset, line and column |
| [hash](hash/README.md) | checksums and hashes that are not cryptographic, one type each with the same methods (`update`, `value`, `digest`, `reset`, `of`, `copy_from`, `of_file`): `crc32`, `crc32c`, `crc64`, `crc64_iso`, `adler32`, the six FNVs, `combine` for the CRCs and Adler-32; `xxh3_64` and `xxh3_128` (XXH3 with a seed, NEON on arm64), `xxh32` and `xxh64` (LZ4's and zstd's checksums), `maphash` (seeded once per process, Go's hash/maphash), `siphash` (SipHash-2-4, a mandatory key); `mixin::hasher` and `req::hasher`, which `crypto`'s digests implement |
| [immutable](immutable/README.md) | the immutable containers (`immutable::vector`, `immutable::list`, `immutable::map`, `immutable::set`: every operation a new version sharing all but the path it changed; the state of a program as a value) |
| [io](io/README.md) | streams (whatever has `read` or `write`, a lambda too, checked by the concepts of `io::req`; `io::reader` and `io::writer` to hold any of them; the mixins over the primitive; `io::stdin`, `io::stdout`, `io::stderr` as objects), `buffered_reader` and `buffered_writer`, `file` over any descriptor with the pool and the reactor behind its async forms, the file system (`stat`, `mkdir_all`, `read_dir`, `walk_dir`), `path`, the process (`args`, `getenv`, the standard streams), a child process (`command`: the fields of `exec.Cmd`, its exit waited for on the reactor), files mapped into memory (`map`) and named shared memory (`shared_memory`); errors as `expected<T, io::error>` |
| [math](math/README.md) | `big_integer`, a whole number of any size with the manners of an `int`, sixteen bytes, a value within `int64_t` allocating nothing, fast multiplication, division and conversions, number theory; `rational`, exact fractions; `random`, ChaCha8Rand with Go's stream from the same key, `next_int`, `next_double`, `shuffle`, `pick`, `permutation` |
| [net](net/README.md) | `ip_address`, `ip_network`, `endpoint` as values; `connection`, `listener`, `udp::socket`; `tcp`, `udp`, `unix_domain`, `dns`; `url` (`net::url`, `net::query_params`, WHATWG); HTTP/1.1 and HTTP/2 in [net::http](net/http/README.md) (`client` with `get`, `post`, `send`, `download`; `server` with Go 1.22 routes; `request`, `response`, `headers`, `cookie`, `status`); TLS 1.3 in [net::tls](net/tls/README.md); every call that waits in two forms (`x` on a thread, `async_x` in a task), absolute deadlines, happy eyeballs |
| [slog](slog/README.md) | structured logging as Go's `log/slog` — `slog::info("msg", "key", value)`, `logger` (made from `slog::options`: the output, text or JSON, the level, `source`, `utc`, `buffered`, sampling; `with`, `group`), text and JSON byte for byte as slog writes them, pairs checked by the compiler, a type described by its fields as a group, nothing managed per record, a batch per worker; `level_var`, `group`, `handler`, `memory`, `record`, `attr`, `value` |
| [time](time/README.md) | dates, the zones of the system's tz database (TZif v1–v4, POSIX TZ), instants in a zone (`datetime`, Go's `time.Time`; `time::now()` follows a test's manual clock), the time elapsed, and their text: RFC 3339, HTTP, e-mail, ISO 8601 and `%` patterns both ways, `txt::format` of time and of `<chrono>` |
| [txt](txt/README.md) | the properties of a code point (the general category, the script, `is_alpha`, `is_emoji`, `columns`) the boundaries of UAX #29 and #14 (`graphemes`, `words`, `sentences`, `line_breaks`, `wrap`) the four normalization forms of UAX #15, the full case mappings with `locale`, searching blind to case or to the way a text was written, the encodings (UTF-16 and UTF-32, the single byte pages, what a header's charset says) and the bidirectional algorithm; collation (`collator`, UTS #10 with the CLDR tailorings), `format` with the pattern of `std::format`, identifiers, IDNA, percent-encoding, regular expressions and `stencil` templates |
