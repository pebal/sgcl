# sgcl::net::ip_address::v4

```cpp
static ip_address v4(uint8_t a, uint8_t b, uint8_t c, uint8_t d) noexcept;
```

The IPv4 address `a.b.c.d`, Go's `netip.AddrFrom4`.

## Parameters

| Parameter | Description |
|---|---|
| `a`, `b`, `c`, `d` | the four bytes, the first the highest |

## Return value

The address; `is_v4()` is true.

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/io.h"
#include "sgcl/net.h"

using namespace sgcl;

int main() {
    auto a = net::ip_address::v4(192, 168, 1, 10);
    println("{} {} {}", a, a.is_v4(), a.is_private());
}
```

Output:

```text
192.168.1.10 true true
```
