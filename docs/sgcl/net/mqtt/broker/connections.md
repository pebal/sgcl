# sgcl::net::mqtt::broker::connections

```cpp
size_t connections() const noexcept;
```

The connections being served now.

## Parameters

None.

## Return value

Their number.

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/async.h"
#include "sgcl/core.h"
#include "sgcl/io.h"
#include "sgcl/net/mqtt.h"
#include "sgcl/net.h"

using namespace sgcl;

int main() {
    net::mqtt::broker b;
    net::listener l = net::tcp::listen("127.0.0.1:0");
    auto serving = async::spawn(b.async_serve(l));
    string url = string::concat("mqtt://", l.local_endpoint().to_string());
    net::mqtt::client c = net::mqtt::client::connect(url).value();
    println("{}", b.connections());
    c.disconnect();
    b.close();
    serving.wait();
}
```

Output:

```text
1
```
