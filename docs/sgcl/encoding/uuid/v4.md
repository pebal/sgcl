# sgcl::encoding::uuid::v4

```cpp
static uuid v4() noexcept;
```

A random UUID, version 4: 122 random bits, the six of the version and the variant fixed. The bits come from the
thread's ChaCha8 stream of [math::random](../../math/random/README.md), keyed from the system and keyed again in
the child of a `fork`; the chance of two alike among a billion is about 10^-19.

## Parameters

None.

## Return value

The UUID.

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/encoding.h"
#include "sgcl/io.h"

using namespace sgcl;

int main() {
    encoding::uuid id = encoding::uuid::v4();
    println(id);
    println("version {}, {} other", id.version(), id == encoding::uuid::v4() ? "no" : "an");
}
```

Sample output:

```text
20ed0b88-04cf-4a6b-941e-c05dc9cbb8e5
version 4, an other
```
