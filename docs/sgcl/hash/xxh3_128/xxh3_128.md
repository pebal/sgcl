# sgcl::hash::xxh3_128::xxh3_128

```cpp
xxh3_128() noexcept = default;                // (1)
explicit xxh3_128(uint64_t seed) noexcept;    // (2)
```

Makes a hasher of no bytes yet.

1. With the seed 0, XXH3 without a seed: its values are those of `xxh3_128::of(data)` and of `xxhsum -H128`.
2. With `seed`: its values are those of `xxh3_128::of(data, seed)`, in every run and on every machine.

## Parameters

| Parameter | Description |
|---|---|
| `seed` | the seed, a number; 0 is XXH3 without one |

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/encoding.h"
#include "sgcl/hash.h"
#include "sgcl/io.h"

using namespace sgcl;

int main() {
    hash::xxh3_128 plain;
    hash::xxh3_128 seeded(42);
    plain.update("hello");
    seeded.update("hello");
    println("{}", encoding::hex::encode(plain.value()));
    println("{}", encoding::hex::encode(seeded.value()));
    println("{} {}", plain.value() == hash::xxh3_128::of("hello"), seeded.value() == hash::xxh3_128::of("hello", 42));
}
```

Output:

```text
b5e9c1ad071b3e7fc779cfaa5e523818
6ce89a0bdba81f088c2f5b7e4cd59e16
true true
```
