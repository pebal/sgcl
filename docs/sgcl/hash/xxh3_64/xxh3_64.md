# sgcl::hash::xxh3_64::xxh3_64

```cpp
xxh3_64() noexcept = default;                // (1)
explicit xxh3_64(uint64_t seed) noexcept;    // (2)
```

Makes a hasher of no bytes yet.

1. With the seed 0, XXH3 without a seed: its values are those of `xxh3_64::of(data)` and of `xxhsum -H3`.
2. With `seed`: its values are those of `xxh3_64::of(data, seed)`, in every run and on every machine.

## Parameters

| Parameter | Description |
|---|---|
| `seed` | the seed, a number; 0 is XXH3 without one |

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/hash.h"
#include "sgcl/io.h"

using namespace sgcl;

int main() {
    hash::xxh3_64 plain;
    hash::xxh3_64 seeded(42);
    plain.update("hello");
    seeded.update("hello");
    println("{:016x}", plain.value());
    println("{:016x}", seeded.value());
    println("{} {}", plain.value() == hash::xxh3_64::of("hello"), seeded.value() == hash::xxh3_64::of("hello", 42));
}
```

Output:

```text
9555e8555c62dcfd
bafa072f07db7937
true true
```
