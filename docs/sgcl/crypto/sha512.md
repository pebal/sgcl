# sgcl::crypto::sha512, sgcl::crypto::sha384, sgcl::crypto::sha512_256

```cpp
#include "sgcl/crypto/sha512.h"   // or "sgcl/crypto/crypto.h"

namespace sgcl::crypto {
    class sha512;       // SHA-512 (FIPS 180-4)        value(): array<byte, 64>
    class sha384;       // SHA-384 (FIPS 180-4)        value(): array<byte, 48>
    class sha512_256;   // SHA-512/256 (FIPS 180-4)    value(): array<byte, 32>
}
```

The SHA-2 digests on words of 64 bits, Go's `crypto/sha512`. SHA-512 is Ed25519's digest and a common choice for HMAC and PBKDF2; SHA-384 is TLS 1.3's `TLS_AES_256_GCM_SHA384` and P-384's; SHA-512/256 gives 32 bytes at SHA-512's speed. SHA-384 and SHA-512/256 are SHA-512 from other initial values, cut to 48 and 32 bytes; being cut, neither is open to length extension. Written from FIPS 180-4, tested against its examples and against OpenSSL.

**The implementation has not been through an independent cryptographic audit.**

## Rules

- **The shape of a hasher** of the [hash module](../hash/README.md), as [`sha256`](sha256.md) has it: `update`, `value()`, `digest()`, `reset()`, `of`, `copy_from`; a copy is a branch. A hasher is about 210 bytes (eight words of 64 bits, a block of 128 bytes, the length), trivially copyable.
- **The length** is counted in bytes in 64 bits: up to 2^64 bytes a message, where the standard allows 2^128 bits.
- **Which one**: SHA-512 is faster than SHA-256 per byte on a processor with no SHA instructions (64-bit words, 128-byte blocks) and slower on one with both sets, as Apple silicon is; choose by the protocol, not by speed.

## Paths

On arm64 the blocks go through the SHA-512 instructions of ARMv8.2 (`SHA512H`, `SHA512H2`, `SHA512SU0`, `SHA512SU1`), two steps an instruction pair, the state in five registers whose names rotate. The processor is asked for `FEAT_SHA512` (`HWCAP_SHA512`), apart from SHA-3's feature: the architecture makes them two options. Elsewhere, and with `SGCL_CRYPTO_PORTABLE`, the compression is plain C++; both paths run every vector in the tests.


## Example

```cpp
#include "sgcl/crypto/crypto.h"
#include "sgcl/encoding/encoding.h"
#include "sgcl/io/io.h"

using namespace sgcl;

int main() {
    println(encoding::hex::encode(crypto::sha512::of("abc")));
    println(encoding::hex::encode(crypto::sha384::of("abc")));
    println(encoding::hex::encode(crypto::sha512_256::of("abc")));
}
```
