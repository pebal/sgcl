# sgcl::crypto::sha512::sha512

```cpp
sha512() noexcept;
sha384() noexcept;
sha512_256() noexcept;
```

Makes a hasher that has hashed nothing: the eight chaining words at the initial values of FIPS 180-4 for SHA-512,
SHA-384 or SHA-512/256, an empty block and a length of zero. Its `value()` is the digest of the empty message.
Copying a hasher is the other way to make one: the copy goes on from where the original stood.

## Parameters

None.

## Complexity

Constant.

## Exceptions

None.

## Example

```cpp
#include "sgcl/crypto.h"
#include "sgcl/encoding.h"
#include "sgcl/io.h"

using namespace sgcl;

int main() {
    println(encoding::hex::encode(crypto::sha512().value()));
    println(encoding::hex::encode(crypto::sha384().value()));
    println(encoding::hex::encode(crypto::sha512_256().value()));
}
```
