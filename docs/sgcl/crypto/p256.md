# sgcl::crypto::p256

```cpp
#include "sgcl/crypto/p256.h"   // or "sgcl/crypto/crypto.h"

namespace sgcl::crypto::p256 {
    class public_key;     // a point of the curve: verifies signatures, the peer of an ECDH key
    class private_key;    // an ECDSA key: signs digests
    class ecdh_key;       // an ECDH key: agrees on a shared secret
}
```

NIST P-256 (secp256r1, prime256v1; FIPS 186-5, SP 800-186), Go's `crypto/ecdsa` and `crypto/ecdh` over `elliptic.P256()`: the curve of TLS, of WebAuthn and passkeys, of JWS's ES256, of most certificates signed with ECDSA. A `private_key` signs ([ECDSA](ecdsa.md)), an `ecdh_key` agrees on a secret (ECDH, SP 800-56A), a `public_key` verifies and is the other side's half of an agreement. Written from FIPS 186-5, SEC 1 and RFC 6979; tested against RFC 6979's vectors, against OpenSSL (signatures both ways on digests of every length, RFC 6979 nonces byte for byte, shared secrets, SEC 1 points accepted and refused alike, PKCS#8, SEC 1 and SPKI both ways) and against Go (signatures, secrets and DER byte for byte), and fuzzed. [`p384`](p384.md) is the same types on P-384.

**The implementation has not been through an independent cryptographic audit.**

## Rules

- **One key, one purpose**, as in Go: a `private_key` is for ECDSA and an `ecdh_key` for key agreement. `to_ecdh()` makes the one from the other for a protocol that needs both from one scalar; there is no way back.
- **Keys from data return `expected`**: `from_bytes`, `from_pkcs8_der`, `from_sec1_der` and `from_pkix_der` give `crypto::error` with `errc::invalid_key` for a scalar not in [1, n − 1] or a point that is not a point of the curve, `errc::malformed` (with the byte's offset) for DER that is not DER, `errc::unsupported` for a key of another algorithm or curve. `generate()` cannot fail.
- **A public key is checked when it is made**: `public_key::from_bytes` takes SEC 1's uncompressed (`04 || X || Y`, 65 bytes) and compressed (`02`/`03 || X`, 33 bytes) forms, and refuses the point at infinity (`00`), the hybrid forms `06`/`07` (as Go does; OpenSSL takes them), a coordinate not below p, a point off the curve and an x with no y — so a `public_key` is always a valid point, and ECDH with it cannot be led into a small subgroup (P-256 has none: its order is prime). `bytes()` gives the uncompressed form, `bytes_compressed()` the compressed one.
- **The private keys are secrets**: the scalar lives in the object (no allocation), the object is move-only, `clone()` makes a second one by name, a move zeroes the source and the destructor zeroes the scalar with stores the compiler cannot drop ([`secure_zero`](secure_zero.md)). Keep a key on the stack or in a `unique_ptr`: in a managed object it stays in memory until the cycle that finds it dead. `bytes()` gives the scalar as a [`secret<32>`](secret.md); `to_pkcs8_der()` and `to_sec1_der()` give it in a [`secret_bytes`](secret.md#secret_bytes), never in managed memory. `from_pem` reads a key from PEM text (`PRIVATE KEY` or `EC PRIVATE KEY`; ECDH's key `PRIVATE KEY`) straight into a `secret_bytes`, and `to_pem` writes a `PRIVATE KEY` block as OpenSSL writes it; for a key file, `from_pem(crypto::read_secret(path))`.
- **The shared secret** is the x-coordinate of d·Q (SEC 1 §3.3.1, what TLS and Go's ECDH give), as a [`secret<32>`](secret.md). It is not a key: put it through [`hkdf`](hkdf.md) with the protocol's salt and info. `shared_secret` returns `expected`, `errc::invalid_key` if the product were the identity, which a valid key and a public key of the curve do not allow. A key moved from is used by no operation: signing, `shared_secret`, `bytes()`, `public_key()` and the DER forms throw `std::logic_error`, as every key of the module does.
- **Constant time** where a secret is: the field and the scalars are Montgomery arithmetic on four 64-bit words with no branch and no memory index that depends on a value; point addition is the complete formulas of Renes, Costello and Batina (no special case for the identity or for doubling); multiplication by a scalar takes each window's multiple by scanning the whole table through masks; the scalar inverse is Fermat's. Parsing and checking a public key, and verifying a signature, work on public data and may take time that depends on it.
- **Formats**: PKCS#8 (`PRIVATE KEY` in PEM) and SPKI (`PUBLIC KEY`) are written as Go's `x509.MarshalPKCS8PrivateKey` and `MarshalPKIXPublicKey` write them (and as OpenSSL does), byte for byte; SEC 1 (`EC PRIVATE KEY`) as Go's `x509.MarshalECPrivateKey`, with the curve and the public key. Reading is strict DER; a SEC 1 scalar with a zero byte too many or too few is read as Go and OpenSSL read it. PEM is [`encoding::pem`](../encoding/pem.md)'s.

## Members

```cpp
class public_key {                                    // a plain value: copied, compared
public:
    static constexpr size_t size = 65;                // 04 || X || Y
    static constexpr size_t compressed_size = 33;     // 02/03 || X
    static constexpr size_t signature_size = 64;      // r || s

    static expected<public_key, error> from_bytes(const slice<const byte>& sec1);
    static expected<public_key, error> from_pkix_der(const slice<const byte>& der);

    array<byte, 65> bytes() const noexcept;
    array<byte, 33> bytes_compressed() const noexcept;
    vector<byte> to_pkix_der() const;

    [[nodiscard]] bool verify_digest(const slice<const byte>& digest, const slice<const byte>& signature) const noexcept;      // DER
    [[nodiscard]] bool verify_digest_raw(const slice<const byte>& digest, const slice<const byte>& signature) const noexcept;  // r || s
    friend bool operator==(const public_key&, const public_key&) noexcept;
};

class private_key {                                   // ECDSA; move-only
public:
    static constexpr size_t size = 32;                // the scalar
    static constexpr size_t signature_size = 64;      // r || s
    static constexpr size_t max_signature_size = 72;  // the longest DER signature

    static private_key generate() noexcept;
    static expected<private_key, error> from_bytes(const slice<const byte>& scalar);
    static expected<private_key, error> from_pkcs8_der(const slice<const byte>& der);
    static expected<private_key, error> from_sec1_der(const slice<const byte>& der);
    static expected<private_key, error> from_pem(const slice<const byte>& text);   // "PRIVATE KEY" or "EC PRIVATE KEY"

    private_key(private_key&&) noexcept;              // the source zeroed
    private_key& operator=(private_key&&) noexcept;
    ~private_key();                                   // the scalar zeroed
    private_key clone() const noexcept;

    secret<32> bytes() const noexcept;
    public_key public_key() const noexcept;
    ecdh_key to_ecdh() const noexcept;

    vector<byte> sign_digest(const slice<const byte>& digest) const;                         // DER; empty: std::invalid_argument
    vector<byte> sign_digest(const slice<const byte>& digest, deterministic_t) const;        // RFC 6979 without the random bytes
    array<byte, 64> sign_digest_raw(const slice<const byte>& digest) const;                  // r || s
    array<byte, 64> sign_digest_raw(const slice<const byte>& digest, deterministic_t) const;
    vector<byte> sign_digest(const slice<const byte>& digest, deterministic_t, hash_id id) const;        // the hash named (SHA-3, SHA-512/256)
    array<byte, 64> sign_digest_raw(const slice<const byte>& digest, deterministic_t, hash_id id) const;
    secret_bytes to_pkcs8_der() const;
    secret_bytes to_sec1_der() const;
    secret_bytes to_pem() const;                           // "PRIVATE KEY"
};

class ecdh_key {                                      // move-only
public:
    static constexpr size_t size = 32;

    static ecdh_key generate() noexcept;
    static expected<ecdh_key, error> from_bytes(const slice<const byte>& scalar);
    static expected<ecdh_key, error> from_pkcs8_der(const slice<const byte>& der);
    static expected<ecdh_key, error> from_pem(const slice<const byte>& text);      // "PRIVATE KEY"

    ecdh_key(ecdh_key&&) noexcept;
    ecdh_key& operator=(ecdh_key&&) noexcept;
    ~ecdh_key();
    ecdh_key clone() const noexcept;

    secret<32> bytes() const noexcept;
    public_key public_key() const noexcept;
    expected<secret<32>, error> shared_secret(const public_key& peer) const;
    secret_bytes to_pkcs8_der() const;
    secret_bytes to_pem() const;
};
```

## Example

```cpp
#include "sgcl/crypto/crypto.h"
#include "sgcl/io/io.h"

using namespace sgcl;

int main() {
    // ECDSA: a key, a signature of a digest, its verification
    auto key = crypto::p256::private_key::generate();
    auto digest = crypto::sha256::of("the message");
    auto sig = key.sign_digest(digest);

    auto pub = key.public_key();
    println(pub.verify_digest(digest, sig) ? "valid" : "forged");
    println(pub.verify_digest(crypto::sha256::of("another message"), sig) ? "valid" : "forged");

    // ECDH: two parties agree on a secret, then derive a key from it
    auto alice = crypto::p256::ecdh_key::generate();
    auto bob = crypto::p256::ecdh_key::generate();
    auto a = alice.shared_secret(bob.public_key());
    auto b = bob.shared_secret(alice.public_key());
    if (a && b && crypto::constant_time::equal(a->bytes(), b->bytes())) {
        auto session = crypto::hkdf_sha256::derive("salt", a, "session key", 32);
        println(session.size() == 32 ? "agreed on a session key" : "no key");
    }
}
```

Output:

```text
valid
forged
agreed on a session key
```
