# sgcl::crypto::x25519

```cpp
#include "sgcl/crypto/x25519.h"   // or "sgcl/crypto/crypto.h"

namespace sgcl::crypto::x25519 {
    class private_key;   // 32 secret bytes and the public key they give; move-only
    class public_key;    // a peer's key, 32 bytes; a value

    inline constexpr size_t public_key_size = 32;
    inline constexpr size_t private_key_size = 32;
    inline constexpr size_t shared_secret_size = 32;
}
```

X25519 (RFC 7748), Go's `crypto/ecdh.X25519()`: Diffie–Hellman on Curve25519. Two parties each make a private key and send the other its public key; each then computes the same 32-byte secret from its own private key and the other's public key, and nobody who saw only the public keys can. It is the key exchange of TLS 1.3, SSH, WireGuard and Signal. Written from RFC 7748, tested against its vectors (the single multiplications, the iterations 1 and 1000 — a million in a test run by hand — and §6.1's Alice and Bob), against OpenSSL on a thousand random key pairs and peer keys of any 32 bytes, and against Go's `crypto/ecdh` on two thousand more.

**The implementation has not been through an independent cryptographic audit.**

## Rules

- **The shared secret is not a key.** Put it through a key derivation — [`hkdf`](hkdf.md) with a label of the protocol — and use what comes out for a cipher or a MAC, as TLS 1.3 and Noise do.
- **Any 32 bytes are a public key**, as RFC 7748 and Go have it: bit 255 is ignored and a value of p = 2²⁵⁵ − 19 or more is reduced. `public_key::from_bytes` refuses only another length (`errc::invalid_key`). A peer's key of small order makes the secret all zeros whatever the private key; `shared_secret` refuses it with `errc::invalid_key` (RFC 7748 §6.1), as OpenSSL and Go do.
- **Any 32 bytes are a private key**, too: they are "clamped" (the low three bits cleared, bit 255 cleared, bit 254 set) each time they are used, not when stored, so `bytes()` gives back what was given, as Go's does; two private keys whose bytes differ only in the bits clamping sets may therefore have the same public key and the same secrets. `generate()` takes them from [`random`](random.md).
- **Constant time.** The ladder of `shared_secret` takes the same 255 steps whatever the bits, swapping its points with masks rather than branches; the public key is computed by Ed25519's fixed-base multiplication, whose table is read whole with masks, and mapped to the Montgomery curve; the field arithmetic has no branch and no memory index that depends on a value. What is secret: the private key, the clamped scalar, every value of the ladder, the shared secret. What is not: the peer's public key and whether the result was zero.
- **A secret, so no copy.** `private_key` holds its 32 bytes in the object's own memory; it is move-only, `clone()` makes a second one, a move leaves the object moved from zeroed, and the destructor zeroes it with stores the compiler cannot drop ([`secure_zero`](secure_zero.md)). Keep a key on the stack or in a `unique_ptr`: in a managed object it stays in memory until the cycle that finds it dead. The shared secret and `bytes()` are [`secret<32>`](secret.md), which zero themselves in turn (`.bytes()` reads them, `==` compares them in constant time); `to_pkcs8_der()` returns a managed `vector<byte>` that holds the key.
- **Keys in files**: `to_pkcs8_der` / `from_pkcs8_der` (PKCS #8, RFC 8410, OID 1.3.101.110) and `to_pkix_der` / `from_pkix_der` (SubjectPublicKeyInfo), byte for byte as OpenSSL writes them. Reading is strict DER; a version 1 PKCS #8 may carry the public key, which must be the private key's (`errc::invalid_key` otherwise), and attributes, which are skipped; another algorithm's key is `errc::unsupported`, broken DER `errc::malformed` with the offset. PEM goes through [`encoding::pem`](../encoding/pem.md).

## Members

```cpp
class private_key {
public:
    static private_key generate();
    static expected<private_key, error> from_bytes(const slice<const byte>& bytes);      // 32 bytes
    static expected<private_key, error> from_pkcs8_der(const slice<const byte>& der);

    private_key(private_key&& other) noexcept;             // other zeroed
    private_key& operator=(private_key&& other) noexcept;
    private_key(const private_key&) = delete;
    ~private_key();                                        // zeroed
    private_key clone() const noexcept;

    x25519::public_key public_key() const noexcept;        // computed once, when the key is made
    secret<32> bytes() const noexcept;                     // the secret bytes, not clamped
    expected<secret<32>, error> shared_secret(const x25519::public_key& peer) const noexcept;
    vector<byte> to_pkcs8_der() const;                     // 48 bytes
    friend bool operator==(const private_key& a, const private_key& b) noexcept;   // constant time
};

class public_key {
public:
    static expected<public_key, error> from_bytes(const slice<const byte>& bytes);       // 32 bytes
    static expected<public_key, error> from_pkix_der(const slice<const byte>& der);
    const array<byte, 32>& bytes() const noexcept;
    vector<byte> to_pkix_der() const;                      // 44 bytes
    friend bool operator==(const public_key& a, const public_key& b) noexcept;
};
```

## Example

```cpp
#include "sgcl/crypto/hkdf.h"
#include "sgcl/crypto/secure_zero.h"
#include "sgcl/crypto/x25519.h"
#include "sgcl/encoding/hex.h"
#include "sgcl/io/print.h"

using namespace sgcl;

int main() {
    // RFC 7748 §6.1's keys; a program makes its own with generate()
    auto alice = crypto::x25519::private_key::from_bytes(
        encoding::hex::decode("77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c2a"));
    auto bob = crypto::x25519::private_key::from_bytes(
        encoding::hex::decode("5dab087e624a8a4b79e17f8b83800ee66f3bb1292618b6fd1c2f8b27ff88e0eb"));

    // each side sends the other its public key, 32 bytes
    auto bob_public = bob->public_key();
    println("Bob's public key: {}", encoding::hex::encode(bob_public.bytes()));

    // and each computes the same secret
    auto secret = alice->shared_secret(bob_public);
    auto same = bob->shared_secret(alice->public_key());
    println(secret == same ? "the same secret" : "different secrets");

    // a key for a cipher is derived from it, never the secret itself
    auto key = crypto::hkdf_sha256::derive("salt", secret, "chat v1 key", 32);
    println("key: {}", encoding::hex::encode(key));
    crypto::secure_zero(key);           // the secrets zero themselves

    // a peer's key of small order gives nothing
    auto zero = crypto::x25519::public_key::from_bytes(array<byte, 32>{});
    auto refused = alice->shared_secret(zero);
    if (!refused) {
        println(refused.error().message());
    }
}
```

Output:

```text
Bob's public key: de9edb7d7b7dc1b4d35b61c2ece435373f8343c85b78674dadfc7e146f882b4f
the same secret
key: e67487567d35287cf3de94cb4fc6291baa707517dd9a2a6c2f110bde51385b4f
the shared secret is zero: the peer's key is of small order
```
