# sgcl::crypto::x509::public_key::p384

```cpp
const crypto::p384::public_key& p384() const;
```

Returns the key as a P-384 public key, when it is one: `kind()` is `key_kind::p384`.

## Parameters

None.

## Return value

The [p384::public_key](../p256-public_key.md).

## Complexity

Constant.

## Exceptions

`logic_error` when the key is of another kind.

## Example

```cpp
#include "sgcl/crypto.h"
#include "sgcl/io.h"

using namespace sgcl;

int main() {
    auto root_text = io::read_text("tests/net/tls_testdata/ca.pem");  // the tree's test CA
    crypto::x509::certificate root = crypto::x509::certificate::from_pem(root_text);

    auto& key = root.public_key();
    if (key.kind() == crypto::x509::key_kind::p384) {
        println("{} bytes", key.p384().bytes().size());
    } else {
        println("not a P-384 key");
    }
}
```

Output:

```text
not a P-384 key
```
