# sgcl::crypto::x509

```cpp
#include "sgcl/crypto/x509.h"   // or "sgcl/crypto.h"

namespace sgcl::crypto::x509 {
    class certificate;
    class certificate_pool;
    struct verify_options;
    using chain = vector<certificate>;
    class name;
    class public_key;
    struct ip_address;
    struct ip_range;
    struct extension;
    enum class reason : uint8_t;
    enum class key_usage : uint16_t;
    enum class ext_key_usage : uint8_t;
    enum class signature_algorithm : uint8_t;
    enum class key_kind : uint8_t;
}
```

`sgcl::crypto::x509` is X.509 certificates (RFC 5280), Go's `crypto/x509`: a [certificate](x509-certificate/README.md) read
from DER or PEM with its names, its key and its extensions, a [pool](x509-certificate_pool/README.md) of certificates, and
the verification of a chain from a leaf through intermediates to a trusted root, with the DNS name or the IP address
the leaf must be for. What TLS needs to decide whether a server is the one it claims to be ([net::tls](../net/tls/README.md)
verifies with it); what code signing, S/MIME and mutual TLS need to know who signed.

Written from RFC 5280, RFC 6125 and X.690; tested field by field against Go's parser on 517 certificates (Go's test
tables and testdata, the system's bundle), against Go's own verdicts on every case of its `verify_test.go` and
`name_constraints_test.go`, against OpenSSL's `X509_verify_cert` (verdict and reason) on chains of every algorithm
made by OpenSSL in the tests, and fuzzed with OpenSSL as the oracle of what DER is. **The implementation has not been
through an independent cryptographic audit.**

## Rules

- **Strict DER, bounded.** A certificate is read in strict DER, and what it may hold is bounded (128 KiB, 64
  extensions, 1024 names in its SAN, …: [parse](x509-certificate/parse.md)); past any bound it is `errc::malformed`.
- **Never an exception from data.** A certificate, however broken, is `errc::malformed` from the readers or a
  verification error from the checks; signatures are checked with the forms that return `false`, never throwing: a
  certificate cannot stop the program.
- **The chain is built on the bytes of the names**, as Go builds it: the parents a pool has for the issuer's name,
  roots before intermediates, at most ten intermediates and a hundred signatures tried
  ([verify](x509-certificate/verify.md)).
- **MD5 and SHA-1 are never accepted.** The signatures verified are RSA PKCS #1 v1.5 and PSS, ECDSA on P-256 and
  P-384, and Ed25519, over SHA-256, SHA-384 and SHA-512.
- **Host names by RFC 6125**: the DNS names of the leaf only, the common name never; a wildcard only as the whole
  leftmost label ([verify_hostname](x509-certificate/verify_hostname.md)). **IP addresses are bytes**, 4 or 16, never
  text ([verify_ip](x509-certificate/verify_ip.md)).
- **Name constraints** of every CA over every name below it: DNS names, IP ranges, email addresses and the domains of
  URIs, permitted and excluded; directory names are not constrained.
- **Why a chain fails** is an error `errc::verification` with a [reason](x509-reason.md) and the certificate at fault
  in its message.
- **Not here: revocation and policy validation.** No CRL, no OCSP, no certificate transparency: a revoked certificate
  verifies until it expires. Policies are read, not validated: a critical policyConstraints, policyMappings or
  inhibitAnyPolicy is an unhandled critical extension.
- **The system's roots** are read once per process from the files Go reads them from
  ([certificate_pool::system](x509-certificate_pool/system.md)).

## Member types

| Type | Definition |
|---|---|
| [certificate](x509-certificate/README.md) | a certificate, read once: its fields, the checks of its signature, its name and its chain |
| [certificate_pool](x509-certificate_pool/README.md) | a set of certificates: roots or intermediates; the system's roots |
| [verify_options](x509-verify_options.md) | what a verification checks against: roots, intermediates, the name, the address, the time, the usages |
| `chain` | `vector<certificate>`: a chain, the leaf first and the root last, what a verification returns |
| [name](x509-name/README.md) | a distinguished name: an issuer or a subject |
| [public_key](x509-public_key/README.md) | a certificate's key: RSA, P-256, P-384, Ed25519 or none |
| [ip_address](x509-ip_address/README.md) | an IP address of a certificate, 4 or 16 bytes |
| [ip_range](x509-ip_range/README.md) | an address and a mask of name constraints |
| [extension](x509-extension.md) | an extension as the certificate has it: its OID, critical, its value |
| [reason](x509-reason.md) | why a chain does not verify (an enumeration, declared in `error.h`) |
| [key_usage](x509-key_usage.md) | the bits of keyUsage (an enumeration of flags) |
| [ext_key_usage](x509-ext_key_usage.md) | the purposes of extKeyUsage known by name (an enumeration) |
| [signature_algorithm](x509-signature_algorithm.md) | the algorithm a certificate is signed with (an enumeration) |
| [key_kind](x509-key_kind.md) | what a certificate's key is (an enumeration) |
