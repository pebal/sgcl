# sgcl::crypto::p384

```cpp
#include "sgcl/crypto/p384.h"   // or "sgcl/crypto/crypto.h"

namespace sgcl::crypto::p384 {
    class public_key;     // a point of the curve: verifies signatures, the peer of an ECDH key
    class private_key;    // an ECDSA key: signs digests
    class ecdh_key;       // an ECDH key: agrees on a shared secret
}
```

NIST P-384 (secp384r1; FIPS 186-5, SP 800-186), Go's `crypto/ecdsa` and `crypto/ecdh` over `elliptic.P384()`: the curve of CNSA and of certificates that ask for 192 bits of security, conventionally with SHA-384 (JWS's ES384, TLS's `ecdsa_secp384r1_sha384`). The types and every rule are [`p256`](p256.md)'s — keys checked when made from data, one key per purpose, the private keys move-only and zeroed, the shared secret the x-coordinate, constant time wherever a secret is, the same formats — on six 64-bit words instead of four, so the sizes differ. Tested as P-256 is: RFC 6979's vectors (A.2.6), OpenSSL and Go both ways, fuzzing.

**The implementation has not been through an independent cryptographic audit.**

## Sizes

| | P-384 | P-256 |
|---|---|---|
| a private scalar (`private_key::size`, `ecdh_key::size`, `bytes()`) | 48 | 32 |
| a public key, uncompressed (`public_key::size`) | 97 | 65 |
| a public key, compressed (`public_key::compressed_size`) | 49 | 33 |
| a raw signature r ‖ s (`signature_size`) | 96 | 64 |
| the longest DER signature (`private_key::max_signature_size`) | 104 | 72 |
| the shared secret (`secret<N>`) | 48 | 32 |

## Members

As [`p256`](p256.md)'s, with the sizes above: `bytes()` of a private key and `shared_secret` give `secret<48>`, `public_key::bytes()` an `array<byte, 97>`, `bytes_compressed()` an `array<byte, 49>`, `sign_digest_raw` an `array<byte, 96>`.

## Example

```cpp
#include "sgcl/crypto/crypto.h"
#include "sgcl/io/print.h"

using namespace sgcl;

int main() {
    auto key = crypto::p384::private_key::generate();
    auto digest = crypto::sha384::of("the message");
    auto sig = key.sign_digest(digest);
    println(key.public_key().verify_digest(digest, sig) ? "valid" : "forged");

    auto alice = crypto::p384::ecdh_key::generate();
    auto bob = crypto::p384::ecdh_key::generate();
    auto a = alice.shared_secret(bob.public_key());
    auto b = bob.shared_secret(alice.public_key());
    println(a && b && crypto::constant_time::equal(a->bytes(), b->bytes()) ? "agreed" : "no agreement");
}
```

Output:

```text
valid
agreed
```
